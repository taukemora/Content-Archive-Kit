# v0.2.0 — Pre-release candidate

**Candidate notes — not a publication announcement.** This candidate adds
optional subscription selection and a digest queue-count fix to the toolkit.
[v0.1.0](v0.1.0.md) remains the published early Pre-release. These notes describe
the preparation snapshot; final source, CI and download checksums belong to the
corresponding GitHub Release metadata after publication.

## Highlights

- **Opt-in subscription selection**, disabled by default. The existing agent
  makes evidence-backed `accept`/`reject`/`defer` judgments; the toolkit validates
  and records them, enforces separate judgment/archive budgets, and checks
  admission before automatic intake. Explicit manual saves remain independent
  of automatic exclusions.
- **Clearer daily accounting.** Digests distinguish editorial decisions,
  budget waits, technical failures and historical open work. Incomplete
  candidate accounting fails `daily finish` rather than reporting success.
- **Correct pending-queue counts.** The latest run or an overview without
  `--run` reads the live queue. A valid zero omits the queue line; a missing file
  retains the snapshot; an unreadable queue reports unknown. Historical runs
  retain their own snapshots, and rendering does not change state.
- **Updated umbrella skill.** Canonical `content-archive` skill 2.1.0 documents
  the selection workflow. Its version is independent of the toolkit version;
  written guidance is not a guarantee of model behavior.

## Requirements and setup

Linux, Python 3.13, Bash and the declared dependencies are required. CI targets
Ubuntu; native Windows and macOS are outside the supported scope. Windows users
can use a Linux environment such as WSL. Node is required for the complete
validation suite, not normal intake.

See [installation](../../README.md#install) and the
[deployment guide](../../skills/content-archive/references/deployment.md).
Existing archives need a pinned, backed-up upgrade that preserves their local
configuration and data. Upstream publication does not install or enable changes
in an existing archive.

## Compatibility and limits

- Missing or disabled `selection.yaml` preserves the legacy collection path.
  A present but invalid policy fails automatic intake visibly; it is not
  silently treated as disabled. Enable selection only with a valid instance
  policy and a verified consumer following the [selection workflow](../subscription-selection.md).
- Previews are capped at 20,000 characters and do not establish completeness.
  Quote validation checks recorded text, not the correctness of an editorial
  conclusion. Deferred items require explicit reassessment; they are not
  automatically re-judged when their review horizon expires.
- Synthetic tests and the documented bounded semantic experiment do not
  establish real-source coverage or accuracy for every model/configuration.
  See [verification and limitations](../subscription-selection.md#verification).
- Browser and live-instance checks are opt-in, not covered by default CI.
  Delivery, NAS and hosted-publication integrations need verification in the
  intended environment; the optional instance test previews delivery only.
