## English

Content Archive Kit is a Markdown-first article archiving toolkit with a command-line workflow and one umbrella Hermes skill. The archive remains the source of truth; hosting, messaging, and scheduled intake are instance choices.

### Included

- Article intake with URL normalization/deduplication, extracted full text, local media, available raw snapshots, and provenance.
- Chinese display titles and length-validated Chinese summaries, preserving original titles.
- Broad categories, optional subcategories, context and tags; rebuildable indexes, full-text search, audits and soft replacement.
- RSS-first source collection with generic RSS and site-specific HTML/docs adapters, retained retry state, explicit failures, and daily digests.
- A local reader and optional encrypted publication that remains disabled until explicitly configured.
- The canonical `content-archive` skill, generic examples, synthetic tests, bilingual documentation, and MIT license.
- Validation infrastructure for Python 3.13 on Ubuntu, plus a documented exact-commit release gate. Actual results are recorded separately, not inferred from the presence of a workflow.

### Requirements and limits

- Python 3.13, Bash and POSIX facilities; Linux is the supported platform, with CI on Ubuntu. Native Windows requires a Linux environment such as WSL. macOS is outside support and CI scope, with no compatibility guarantee. Acceptance is established by the candidate's actual Ubuntu CI result.
- Install the declared requirements in a clean toolkit or instance environment. Node is required for the complete validation/interop suite, not for ordinary archive operation. Browser acceptance additionally needs Playwright/Chromium and is opt-in.
- No AI service is bundled: Chinese editorial work is supplied by the user/agent and validated by the toolkit. A fetch failure is not proof of complete coverage.
- Public CI uses synthetic fixtures. Browser and real-instance tests are optional; their skips do not establish browser, production, NAS, or hosted-site acceptance.
- Upstream publication does not install a skill, change a cron job, send a message, publish articles, or upgrade an existing private archive. Installation and upgrades are pinned, reviewed operations with backup and rollback.
- No reader-performance improvements are included in this preparation unit.

## 简体中文

Content Archive Kit 是一套以 Markdown 为事实源的文章收藏工具，包含命令行流程和一个伞形 Hermes 技能。收藏库自身保持事实源地位；托管、消息发送与定时采集由各实例自行选择。

### 包含内容

- 文章收藏：URL 规范化与去重、提取全文、本地媒体、可用时的原始快照及来源信息。
- 中文展示标题和经长度校验的中文摘要，同时保留原文标题。
- 一级分类、可选二级分类、场景与标签；可重建索引、全文检索、审计及软替换。
- RSS 优先采集：通用 RSS 及特定站点 HTML/文档适配器，保留重试状态、明确呈现失败并生成日报。
- 本地阅读页，以及默认关闭、需显式配置的可选加密发布。
- `content-archive` 技能原件、通用示例、合成测试、双语文档与 MIT 许可证。
- Ubuntu 上的 Python 3.13 验证基础设施，以及精确提交的发布验收门槛。实际结果单独记录，不能从“存在工作流”推断为已通过。

### 环境与边界

- 需要 Python 3.13、Bash 和 POSIX 能力；支持平台为 Linux，CI 使用 Ubuntu。原生 Windows 须使用 WSL 等 Linux 环境。macOS 不在支持与 CI 范围内，不承诺兼容。验收以候选提交的真实 Ubuntu CI 结果为准。
- 在干净的工具包或实例环境中安装声明依赖。完整验证及互操作测试需要 Node，日常收藏操作不要求 Node；浏览器验收额外需要 Playwright/Chromium，并须显式开启。
- 不捆绑 AI 服务：中文编辑由用户或代理完成，工具包负责校验。抓取失败不代表覆盖完整。
- 公开 CI 只使用合成 fixtures。浏览器与真实实例测试为可选项；跳过不代表浏览器、生产实例、NAS 或线上站点已验收。
- 上游发布不会安装技能、修改 cron、发送消息、发布文章或升级私人收藏库。安装和升级须固定版本、经过审核并保留备份与回滚。
- 本轮准备工作不包含阅读器性能改造。
